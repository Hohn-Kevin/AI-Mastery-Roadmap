# AI Mastery Roadmap

## Purpose

This roadmap defines the long-term direction of the learning journey. It is intentionally high-level: detailed curricula, missions, projects, and assessments are introduced later through scoped issues.

The goal is not merely to learn Python. The goal is to build, step by step, the practical and theoretical foundation required for strong AI engineering and eventually research-oriented work.

## Roadmap Principles

- Progress through increasingly difficult, project-based levels.
- Learn concepts close to the point where they are applied.
- Prefer real artifacts and working projects over isolated exercises.
- Demonstrate understanding before advancing.
- Revisit weak areas when later work exposes gaps.
- Keep the learning state in the repository rather than relying on one chat or one AI system.
- Use AI as tutor, reviewer, and challenger during learning, not as a replacement for the learner's own implementation work.

## Levels

### Level 1 — Python Foundations

Build the ability to write small Python programs independently.

Core direction:

- variables and basic data types
- conditions
- loops
- functions
- lists and dictionaries
- files and basic input/output
- fundamental problem decomposition

Level outcome:

The learner can design and implement small, useful programs without needing the solution written for them.

### Level 2 — Software Engineering Foundations

Move from isolated programs toward disciplined software development.

Core direction:

- Git and collaborative workflow
- modules and packages
- virtual environments and dependencies
- error handling
- logging
- JSON and structured data
- testing
- type hints
- object-oriented programming where appropriate

Level outcome:

The learner can structure, test, document, and maintain a small software project using professional development practices.

### Level 3 — Professional Python

Develop deeper Python and systems skills required for larger applications.

Core direction:

- APIs and networked applications
- databases
- concurrency and asynchronous programming
- multiprocessing and performance
- architecture and design trade-offs
- packaging and reusable libraries

Level outcome:

The learner can build and reason about non-trivial Python systems and make deliberate engineering decisions.

### Level 4 — Machine Learning Foundations

Learn core machine-learning ideas by implementing important algorithms before relying on high-level frameworks.

Core direction:

- data preparation and evaluation
- linear regression
- gradient descent
- k-nearest neighbors
- Naive Bayes
- decision trees
- classification and regression fundamentals
- overfitting, validation, and metrics

Level outcome:

The learner understands how common machine-learning algorithms work and can implement and evaluate simplified versions independently.

### Level 5 — Deep Learning

Move from classical machine learning to neural networks and modern deep-learning tooling.

Core direction:

- NumPy-based numerical thinking
- neural-network fundamentals
- backpropagation
- PyTorch
- convolutional networks
- recurrent networks and sequence models
- training, debugging, and evaluation

Level outcome:

The learner can implement, train, evaluate, and diagnose neural networks while understanding the mechanisms beneath the framework APIs.

### Level 6 — Transformers

Build a first-principles understanding of the transformer architecture.

Core direction:

- attention
- self-attention
- multi-head attention
- positional information
- transformer blocks
- token and sequence representations
- training a small transformer model

Level outcome:

The learner can implement and explain the major components of a transformer and reason about how they interact.

### Level 7 — LLM Engineering

Work with modern language-model systems and the engineering techniques used around them.

Core direction:

- language-model training concepts
- fine-tuning
- LoRA and parameter-efficient adaptation
- retrieval-augmented generation
- embeddings
- quantization
- evaluation
- inference and deployment trade-offs

Level outcome:

The learner can build, evaluate, and reason about practical LLM-based systems without treating the model stack as a black box.

### Level 8 — AI Research Practice

Develop the habits required to understand, reproduce, and eventually extend research.

Core direction:

- reading papers critically
- reproducing published results at an appropriate scale
- designing controlled experiments
- ablations and baselines
- statistical and methodological reasoning
- documenting negative as well as positive results
- identifying open questions
- forming and testing original hypotheses

Level outcome:

The learner can independently study technical literature, reproduce selected ideas, design meaningful experiments, and communicate results rigorously.

## Progression

Levels are directional rather than rigid walls. Some topics may appear earlier when a project requires them, and later work may trigger review missions in earlier skills.

Advancement is based on demonstrated understanding and completed work, not elapsed time, XP, or arbitrary percentages.

Detailed level curricula belong in later issues. This document defines the long-term route only.
