# Project Scope

## Purpose

AI Mastery Roadmap is a long-term, project-based learning repository for progressing from foundational programming skills toward advanced AI engineering and research practice.

It is not only a collection of exercises. The repository is intended to serve simultaneously as:

- a structured learning path;
- a persistent record of learning state;
- a portfolio of increasingly difficult work;
- a durable handoff point for future human or AI tutors.

## Long-Term Direction

The learning path begins with practical programming foundations and progresses through software engineering, professional Python, machine learning, deep learning, transformers, LLM engineering, and research practice.

Python is the first major tool, not the final objective.

## In Scope

The repository may contain:

- high-level roadmap documentation;
- detailed level curricula;
- learning missions and larger challenges;
- learner-built projects;
- reflections and evidence of demonstrated skills;
- progress state;
- supporting resources;
- repository governance and workflow documentation;
- tooling that becomes useful for maintaining or validating the learning system.

## Out of Scope by Default

The repository should not expand into unrelated product development merely because an idea is interesting.

New systems, automation, abstractions, dashboards, or integrations should be introduced only when they support the learning journey or the maintenance of this repository and have a clearly scoped issue.

The repository is also not intended to become dependent on one AI provider, one chat history, or one proprietary tutor implementation.

## Public Learning Journey

The repository is public and should remain suitable as a long-term record of progression.

That does not require hiding mistakes. It requires keeping the history understandable, the accepted `main` branch coherent, and completed work honest about what was learned and where assistance was required.

## Scope Changes

Material changes to the purpose of the repository, the learning philosophy, the level structure, or the role of AI assistance should be proposed explicitly through a dedicated issue and reviewed before becoming part of `main`.
